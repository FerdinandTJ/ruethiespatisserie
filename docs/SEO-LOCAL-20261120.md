## Dasar keputusan

Ekspor Search Console milik pemilik memakai filter tiga bulan, dengan baris harian tersedia 22 Oktober–18 November 2026: 36 klik, 201 tayangan, CTR 17,9%. Seluruh 36 klik pada tabel halaman menuju beranda. Tabel kueri hanya menjelaskan 4 klik dan 34 tayangan; jangan menganggap seluruh klik lain berasal dari merek. Angka tayangan per halaman tidak dijumlahkan menjadi total properti karena agregasinya berbeda.

Kueri yang terlihat antara lain `toko kue di lippo cikarang` (2 tayangan, posisi rata-rata 10,5), `toko kue lippo cikarang` (1; 10), `dessert cikarang` (2; 17,5), `bakery terdekat` (2; 25), dan `toko kue terdekat` (2; 35,5). Sampel terlalu kecil untuk menyebut posisi stabil atau memprediksi volume permintaan.

Inspeksi URL terbaru yang dikirim pemilik menunjukkan Menu dan Platter sudah terindeks, meskipun laporan Page indexing lama masih menandainya discovered. Tes aktif Lapis Marble lolos akses Google; status available belum sama dengan indexed. Pemilik sudah meminta pengindeksan Lapis Marble dan Platter.

Pemeriksaan HTTP produksi sebelum implementasi menemukan `/menu` → 301 → `/menu/` → 200 tanpa loop. Sembilan URL aktif pada daftar discovered merespons 200, canonical sesuai, meta robots index. URL Lapis Surabaya lama sengaja 404 sesuai keputusan pemilik, bukan dipulihkan atau diarahkan. Sitemap berhasil, berisi 18 URL, dan sudah memakai Lapis Marble. Tidak ada alasan dari pemeriksaan ini untuk mengubah redirect.

## Dua draft Indonesia, bukan penerbitan otomatis

`admin/seo-local-article-seeds.php` (hanya CLI, akses HTTP 404) berisi:

- Cara Memilih Snack Box untuk Rapat Kantor.
- Checklist Memesan Konsumsi Kantor: Apa Saja yang Perlu Disiapkan?

Keduanya disiapkan sebagai pasangan artikel Inggris yang sudah ada di hosting. CLI `admin/seo-content-upgrade.php`:

- `--check` hanya melaporkan rencana; tidak menulis store atau backup.
- `--apply` membaca ulang di dalam lock artikel, backup sebelum menulis, menambah draft dan audit, memperbarui revision agar form lama ditolak.
- Tidak mengubah flag Artikel, status publik, artikel Inggris atau editan/soft-delete draft sebelumnya. Idempoten.
- Melewati draft jika ID/slug sudah ada, pasangan terjemahan sudah dibuat, sumber Inggris tidak ada, atau kategori `panduan` sudah dihapus. Alasan tampil di hasil. Jangan memaksa kategori hosting kembali ke default; gunakan admin untuk menulis draft pada kategori yang diinginkan bila perlu.
- Menyalin referensi sampul dari sumber Inggris hanya jika file WebP valid tersedia, tanpa mengubah berkas gambar. Pemilik tetap perlu memeriksa foto dan alt text Indonesia; jika tidak tersedia, draft tanpa sampul.
- Tidak memuat kredensial PO atau mengubah database. Store rusak, validasi atau backup gagal menolak penerapan.

## Deployment setelah instruksi push

Dari checkout produksi, hentikan sementara pengeditan artikel, backup kode/konten dan data privat di luar public_html, simpan perubahan hosting, lalu pull main tanpa menimpa JSON hosting. Setelah pull:

```bash
php admin/seo-content-upgrade.php --check
php admin/seo-content-upgrade.php --apply
php admin/seo-content-upgrade.php --check
```

Apply bersifat opsional jika pemilik memilih membuat versi Indonesia langsung melalui admin. Ini berbeda dari `seo-upgrade.php` untuk metadata produk; tidak perlu menjalankan upgrade keamanan atau impor phpMyAdmin.

Di Admin → Artikel → Belum diterbitkan: periksa dua draft, kategori, produk terkait, bahasa Indonesia, pasangan Inggris, sampul dan deskripsi foto. Preview, edit sesuai fakta bisnis, simpan lalu terbitkan hanya setelah pemilik setuju. Draft tidak masuk sitemap atau blok publik sebelum diterbitkan. Tidak ada artikel produksi yang diterbitkan oleh pekerjaan kode ini.

## Pemeriksaan dan evaluasi

- `php tests/seo-local-content.php`: check read-only, backup gagal, dua draft, preservasi English/flag/akun/katalog, idempotensi terhadap edit/soft-delete dan JSON rusak.
- `php tests/seo-public.php`: HTML server, meta/canonical/FAQ/schema, internal link, filter noindex, sitemap, CMS menu/FAQ/galeri, 404/503 dan pengamanan XSS.
- `php tests/articles.php`: autentikasi, editor visual, kategori, publikasi/penyembunyian dan isolasi data.
- Browser fixture lokal pada 320/390/768/1440px: tanpa overflow, ID/EN, filter, WhatsApp, animasi, reduced motion dan tanpa JavaScript. Pengujian Chromium lokal bukan verifikasi Safari/iPhone asli atau skor Lighthouse hosting.
